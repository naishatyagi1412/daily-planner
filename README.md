# Daily Planner ⏰

A simple Python-based application to manage daily tasks and track their completion.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Persistent data storage using JSON

## Tech Used
- Python
- JSON (for saving data)

## Purpose
This project was created to help organize daily activities by allowing users to track and update their tasks efficiently.

## Future Improvements
- Add delete task feature
- Add deadlines and priorities
- Improve user interface
